# Mini RPG Guardião da Floresta

## Descrição
O Mini RPG Guardião da Floresta foi desenvolvido em HTML, CSS & JavaScript para rodar no
navegador. No jogo, o guardião precisa defender sua floresta de um slime sombrio, durante a 
batalha é possível defender, atacar utilizar poções para aumentar sua vida.
O jogo possui um sistema de dano aleatório, defesa, ataque, histórico de batalhas e um 
salvamento automático utilizando `localStorage`.

## Objetivo
O principal objetivo foi desenvolver um jogo simples e interativo 
para praticar conceitos de lógica e desenvolvimento web.

## Tecnologias Utilzadas
Nesse jogo foi utilizadas:
- HTML = estrutura da página;
- CSS = estilização da página;
- JavaScript = lógica e funcionamento da página;
- DOM = manipulação dos elementos da página;
- LocalStorage = salvamento do progresso.

  ## Funcionalidades
- **Atacar** o inimigo;
 
 - **Defender** para reduzir o dano levado;
 - **Usar poções** para recuperar sua vida;
 - **Visualizar** a barra de vida do guardião tanto a do inimigo;
 - Sistema de **dano aleatório**;
 - **Histórico de batalha**;
 - **Salvamento automático**;
 - **Recuperar** progresso anterior;
 - Opção para **apagar o progresso**;
 - Opção para **jogar novamente**;


 ## Como Jogar
 1. Abra o jogo no navegador;
 2. O Guardião irá começar com 100% de vida;
 3. O Slime sombrio com 80% de vida;
 4. Escolha uma opção
    - **Atacar**  
    - **Defender**  
    - **Usar Poção**  
  5. Aguardar a reação da criatura;
  6. Continuar escolhendo suas ações durante a jogada;
  7. E derrote o inimigo para proteger a floresta.
